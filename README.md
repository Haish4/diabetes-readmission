# Diabetes Hospital Readmission Prediction

(Draft - to be completed after EDA and modeling.)

## Problem
Hospitals are penalised for patients readmitted within 30 days of discharge. Given a diabetic
patient's encounter data (demographics, diagnoses, lab results, medications, prior visits),
predict whether they will be readmitted in <30 days, so care teams can prioritise follow-up.

## Dataset
UCI "Diabetes 130-US hospitals for years 1999-2008" - https://archive.ics.uci.edu/dataset/296
Download instructions: see `data/README.md`.
